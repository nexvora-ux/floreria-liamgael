# Florería Liam Gael - aplicación PWA

Aplicación web instalable construida siguiendo el diseño de referencia facilitado por el cliente. El aspecto floral se conserva mediante una imagen optimizada del diseño original, mientras que las zonas de interacción son enlaces y controles HTML reales. Los cinco productos del carrusel usan fotografías reales aportadas por el cliente.

## Contenido

- Identidad visual cyan y logotipo oficial.
- Carrusel desplazable con categorías: Ramos Coreanos, Decoración de carro, Arreglos de Cumpleaños, Arreglos de condolencias y Arco y conos para anda.
- Botones interactivos para WhatsApp, catálogo, pedidos, llamadas, ubicación y horario.
- Redes sociales Instagram, Facebook y TikTok.
- Guardar/instalar aplicación y compartir, con imagen Open Graph que incluye logotipo oficial.
- Mensaje de **delivery a todo Lima** y horario **24 horas, todos los días del año, incluidos feriados**.

## Publicar

1. Descomprime el paquete. Sube **el contenido de la carpeta `floreria-liamgael`** a la raíz del repositorio `nexvora-ux/floreria-liamgael` (no subir la carpeta contenedora).
2. En GitHub entra en `Settings → Pages` y selecciona `Deploy from a branch`, rama `main`, carpeta `/ (root)`, y guarda.
3. Una vez publicada, la dirección prevista es `https://nexvora-ux.github.io/floreria-liamgael/`.
4. En Android: Chrome → ⋮ → Instalar aplicación. En iPhone: Safari → Compartir → Añadir a pantalla de inicio.

No se publica automáticamente en GitHub ni se crea un APK. Se requiere servir el sitio por HTTPS para instalar la PWA y para que los metadatos de compartir funcionen en las plataformas compatibles.

## Nota de diseño

La composición principal reproduce la imagen de referencia; para lograr fidelidad visual se usa parte de esa imagen como fondo. Es una interfaz de proporción fija adaptada al ancho del móvil, no una reconstrucción independiente de todos los adornos. Las categorías sustituyen las tarjetas del mockup con fotografías reales.
